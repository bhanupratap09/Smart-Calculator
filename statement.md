# Problem Statement

## Problem Statement
Basic calculators cannot handle matrix inversion, complex-number
arithmetic, base conversion or statistics, and switching between separate
tools for each domain is inefficient. This project provides one reliable
command-line tool for all of them, with input validation so that mistakes
never crash the program.

## Scope of the Project
A single-user, console-based application covering arithmetic, algebra,
trigonometry, matrices, complex numbers, combinatorics, statistics and
conversions. It does not include a GUI, graphing or symbolic mathematics.

## Target Users
Students and engineers who need quick advanced calculations from a terminal.

## High-Level Features
1. Arithmetic, powers and logarithms
2. Trigonometry and quadratic equation solving
3. Matrix and complex-number operations
4. Combinatorics and descriptive statistics
5. Unit and number-base conversions
